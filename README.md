## 🎨 Design System & Visual Highlights

The portfolio features a curated, dark-mode-first aesthetic with dynamic theme switching and modern web design principles:

* **Theme Architecture:** Light & Dark theme support with smooth theme transitions (leveraging the View Transitions API) and `localStorage` persistence.
* **Typography:** Premium Google Fonts pairing — *Syne* for headers, *DM Mono* for code/meta details, *Instrument Serif* for accents, and *Inter* for body readability.
* **UI & Micro-Animations:** Glassmorphic navigation bar, subtle light glare sweep card animations, pulsing availability indicators, interactive certificate modals with preview/download options, and scroll-triggered section reveal animations.
* **Performance-First:** Pure Vanilla HTML5, custom CSS variables, and native JavaScript (`ui-core.js`). Zero external UI runtime overhead for ultra-fast loads.

## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/A-b-h-i-n-a-V-01/github-portfolio.git
   cd github-portfolio
   ```

2. **Launch locally:**
   Simply open `index.html` directly in any web browser, or spin up a quick Python HTTP server:
   ```bash
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000` in your web browser.
